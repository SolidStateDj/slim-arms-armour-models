# Slim Arms Armor Models
[![Modrinth][img-modrinth]][url-modrinth]

Just a simple tweak that shrinks the size of the chestplate's shoulder pads on players using slim arms.

Does not affect players using normal arms.


**⚠️ Requires [[EMF] Entity Model Features](https://modrinth.com/mod/entity-model-features) ⚠️**
